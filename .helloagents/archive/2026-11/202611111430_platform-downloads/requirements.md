# 平台下载细分 — 需求

确认后冻结，执行阶段不可修改。如需变更必须回到设计阶段重新确认。

## 核心目标
下载者能分别找到 Linux x86_64、Linux ARM64 和已发布 Android 的正确安装包。

## 功能边界
Linux 两个架构分别选择最新稳定版本和格式；版本记录可按两个架构和 Android 筛选；Android 有下载入口与安装说明；静态首页与动态页面使用同一发布清单。

## 非目标
不修改 Cloud 上的发布或签名，不自动部署远程站点，不新增框架或依赖。

## 技术约束
延续纯静态 HTML / CSS / JavaScript、Node 内置模块和既有设计令牌。保留旧版本历史、无脚本可下载及 GitHub Pages 工作流。

## 质量要求
验证各架构版本互不遮蔽、真实文件链接、键盘操作、窄屏适配、请求失败回退及数据输出转义。测试与构建无真实密钥依赖。
