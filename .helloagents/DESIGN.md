# PointCloud Studio 下载站 设计系统

## 产品表面
公开下载页：首屏选择安装包，软件界面区展示真实点云回放与渲染设置，版本记录核对文件和发布日期，安装区提供平台步骤。

## 美学方向
延续现有石墨色工具界面。用真实版本号、架构与文件信息建立可信度，琥珀色只强调首个下载动作。

## 设计 token
沿用 public/tokens.css：paper 为背景，paper-2 / paper-3 为表面，ink / ink-2 / muted 为文字，rule 为边框，accent 为主动作，cool 为版本，error / success 为语义色。
标题与正文使用 Host Grotesk 和现有中文后备字体；版本、日期、文件大小使用 Atkinson Hyperlegible Mono。间距、圆角和动效统一取既有变量。

## 布局策略
桌面保留左侧说明、右侧下载面板。Linux 区域内分 x86_64 与 ARM64，两列独立展示版本和格式；窄屏切换为单列，表格改为纵向文件记录。

## 组件与模式
单个安装包用直接下载链接，多个格式用原生 details / summary 展开选择。版本记录使用带 aria-pressed 的平台筛选，Linux 两个架构独立筛选。
格式列表使用悬浮层，展开不占据布局空间；空间不足时向上展开，手机限制高度并支持列表内滚动。保留外部点击、Escape 和选项点击后收起。
两个 Linux 架构的 deb 选项均以文字标注「推荐」，同时保留 Debian、Ubuntu 系的适用范围说明。
筛选栏直接随 HTML 显示，交互使用普通脚本，不依赖远程请求或模块加载；异步刷新保留用户选择和键盘焦点。

## 状态覆盖
加载期间保留已生成的静态内容；成功后替换为当前清单；请求失败保留内容并就地说明；缺少某平台文件时仅显示一次暂无说明，不展示无效下载按钮。

## 记忆点
大号等宽版本数字，结合克制的琥珀色下载动作和细分隔线。

## 动效策略
由 public/radar-scene.js 与 public/motion.js 分别提供场景和页面反馈（渐进增强，经典脚本，零依赖）：
首屏背景是 Canvas 手写 3D 投影的雷达点云地形，带旋转扫描与指针探测点亮；一次入场编排（文案错峰、面板入位），版本号始终显示真实值；
下载卡片轻微 3D 倾斜、筛选滑动指示器、格式菜单弹出、命令复制、顶部滚动进度、主截图轻微滚动视差。
滚动时不做逐区块入场。prefers-reduced-motion 时点云只画一帧，切换偏好立即停止动态效果；离屏和后台暂停点云。页面增强初始化结束立即解除内容隐藏；脚本未加载时 2.6 秒兜底显示全部内容。
真实截图采用完整主界面加工具细节的层级，静态展示而非轮播；图片保留宽高并延迟加载，支持原生链接查看大图，本地文件名与路径必须遮挡。

## 无障碍要求
控件支持键盘、可见焦点、原生语义和至少 44px 点击高度。窄屏不横向溢出；架构与状态使用文字说明，不只依赖颜色。

## 内容语气
直接写明平台、架构、版本、格式与适用发行版；ARM 指当前实际发布的 ARM64。平台名称和文件名以真实清单为准。

## 禁止事项
禁止混合 Linux 架构后仅显示一个最新版本，禁止用旧链接充当已撤销版本，禁止编造兼容性或安装保证。

## 约束定义
保持下载、软件界面、版本记录、安装的独立职责；沿用字体和配色；首屏仅一个填充色主按钮。

## 实现备注
模型与格式化规则位于 public/releases-model.js，HTML 渲染位于 public/releases-view.js。浏览器和静态生成复用相同渲染，public/downloads.css 仅扩展平台布局。桌面 1280×800 与手机 375×812 验收。
